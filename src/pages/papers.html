papers

Written up for human readers.

A checked lemma is a line in a proof assistant. A paper is the same result written so a person can read the statement, the mechanism and the place where it stops. Review state is shown on every one, because the checker verifies proofs and not prose.

What the checker does and does not decide. It decides whether the file proves the recorded statement with no gap and no axiom outside the standard three. It does not decide whether the statement says what its plain English sentence says. A seat that did not write the lemma reads it for exactly that.
